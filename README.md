## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Rajibul-Molla/React-inDepth.git
cd React-inDepth

# Open any lesson
cd 10.useEffect_Hook

# Install and run
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

<details>
<summary><b>Requirements</b></summary>

- Node.js 18 or higher
- npm 9 or higher
- Git

</details>

<details>
<summary><b>Troubleshooting</b></summary>

- **`npm install` fails:** delete `node_modules` and `package-lock.json`, then run it again.
- **Port already in use:** run `npm run dev -- --port 3000`.
- **Blank page:** open the browser console and check for errors.
- **Wrong folder:** each lesson is its own project, so run the commands inside that lesson's folder.

</details>

## 🧠 Concepts Covered

<details open>
<summary><b>🔹 Fundamentals</b></summary>

- Components, JSX and rendering
- Props and children
- Conditional rendering
- Lists and keys
- Event handling
- Forms

</details>

<details open>
<summary><b>🔹 Hooks</b></summary>

| Hook | What it does |
|------|--------------|
| `useState` | Local component state |
| `useEffect` | Side effects and lifecycle |
| `useEffectEvent` | Non-reactive logic inside effects |
| `useContext` | Shared data without prop drilling |
| `useReducer` | Complex state logic |

</details>

<details open>
<summary><b>🔹 Architecture and Routing</b></summary>

- Props drilling and how to avoid it
- Context API
- React Router (multi-page navigation)
- Reducer-based state management
- Project structure for real apps

</details>
